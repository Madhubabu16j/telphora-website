# Telphora Website

Official marketing site for **Telphora** (telphora.com) — AI-native cybersecurity company.

## Project structure

```
telphora-website/
├── index.html          # Home
├── platform.html       # Platform — interactive capability tabs
├── agents.html         # AI Agents — how-it-works stepper + FAQ
├── company.html        # Company — story, principles, who we serve
├── contact.html        # Contact — email-first with prefilled subjects
├── css/
│   └── styles.css      # Full design system (dark theme, responsive)
├── src/
│   └── main.ts         # TypeScript source for site interactions
├── js/
│   └── main.js         # Compiled output (generated by `npm run build`)
├── assets/
│   └── favicon.svg     # "T" mark in brand gradient
├── package.json        # Build scripts + TypeScript dev dependency
├── tsconfig.json       # Strict TypeScript config
└── README.md
```

## Development

```bash
npm install     # install TypeScript
npm run build   # compile src/main.ts → js/main.js
```

`npm run typecheck` verifies types without emitting.

## Deploy: GitHub → Cloudflare Pages

1. **Push to GitHub** — this repo.
2. **Cloudflare dashboard → Workers & Pages → Create → Pages → Connect to Git.**
3. Select the repo. Build settings:
   - **Build command:** `npm run build`
   - **Build output directory:** `/` (root — it's plain static files)
4. **Custom domain:** Pages project → Custom domains → add `telphora.com` (and `www.telphora.com` if wanted). Cloudflare adds the DNS records automatically since the domain is on Cloudflare Registrar.
5. Every `git push` to the connected branch redeploys automatically.

## Notes

- Contact is email-only: every CTA links to `mailto:founder@telphora.com`.
- No fake claims anywhere on the site — no invented logos, testimonials, stats, certifications, or partnerships.
- Fully responsive; respects `prefers-reduced-motion`.
